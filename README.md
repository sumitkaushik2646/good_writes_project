# Good Writes - Super Admin Dashboard 🚀

> A full-stack God Mode dashboard for author outreach automation and Goodreads review fulfillment.

This repository contains the core web architecture for the Good Writes platform. It is designed to provide granular access controls, custom audit logging, and direct file-level management.

## 🛠 Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript
* **Backend Environment:** Node.js, Express
* **Database & Auth:** Firebase Firestore, Firebase Authentication

## ⚙️ Core Features
* **Author Outreach Automation:** Streamlines the process of connecting with authors.
* **Review Fulfillment System:** Tracks and manages Goodreads review pipelines.
* **Granular Access Control:** Role-based dashboard (Super Admin) for complete operational control.
